# Learning C++
 
This repo documents my journey learning C++ through **C++ Primer Plus, 6th Edition** by Stephen Prata.
 
For each chapter, I include:
- A summary of my notes on the topics covered
- The exercises and examples from the book, implemented and compiled myself
The goal is to build a solid foundation in C++ while keeping a reference I can come back to later.
 
## Setup
 
Compiled and tested using MinGW-w64 (via MSYS2) on Windows.
 
```bash
g++ file.cpp -o file.exe
./file.exe
```
