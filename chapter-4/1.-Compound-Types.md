### Introducing Arrays

An *array* is a data form that can hold several values, all of one type.
To create an array, you use a declaration statement. An array declaration should indicate three things:

- The type of value to be stored in each element
- The name of the array
- The number od elements in the array

For example, the following declaration creates an array named *months* that has 12 elements and each element hold a type *short* value.

```cpp
short months[12];
```
The [yam analisis](../programs/chapter-4/arrayone/arrayone.cpp) program demostrates a few properties of arrays, including declaring an array, assignign values to array elements, and initializating an  array.


The compiler does not check to see if you use a valid subscript. For instance, the compiler
won't complain if you assign a value to the nonexistent element `months[1o1]`. But that
assignment could cause problems when the program runs, possibly corrupting data or code,
possibly causing the program to abort. So it is your responsibility to make sure that your
program uses only valid subscript values.
