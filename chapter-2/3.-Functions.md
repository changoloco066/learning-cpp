## Functions

Functions are the modules from which C++ programs are built; they are essential to C++ OOP definitions.

In C++, functions come in two varieties: those that return values and those without them.

### Using a *Function* That Has a Return Value

A function that has a return value produces a value that you can assign to a variable or use in some other
expression. Suppose you want to calculate the square root of 6.25 and assign it to a variable `x`.

```cpp
x = sqrt(6.25);  // returns the value 2.5 and assigns it to 'x'
```

The value in the parentheses is information that is sent to the function; this value is called an *argument*
or *parameter*. The `sqrt()` function calculates the answer to be 2.5 and sends the value back to the calling
function; the value sent back is termed the *return value* of the function.

Before the C++ compiler uses a function, it must know what kind of arguments the function uses and what kind of
return value it has. If it lacks this information, the compiler won't know how to interpret the return value.
The C++ way to convey this information is to use a *function prototype* statement.

A *function prototype* does for functions what a variable declaration does for variables: it tells what types
are involved. For example, the library defines the `sqrt()` function to take a number with (potentially) a
fractional part as an argument and to return a number of the same type.
The function prototype for `sqrt()` looks like this:

```cpp
double sqrt(double); // function prototype
```

The initial `double` means `sqrt()` returns a type `double` value. The `double` in the parentheses means `sqrt()`
requires a `double` argument. So this prototype describes `sqrt()` exactly as used in the following code:

```cpp
double x;       // declare x as a type double variable
x = sqrt(6.25);
```

### Function Variables

Some functions require more than one item of information. These functions use multiple arguments separated by
commas.

- Ex (sqrt.cpp)

```cpp
double pow(double, double); // prototype of a function with two arguments
```

Other functions take no arguments:

```cpp
int rand(void);     // prototype of a function that takes no arguments
```

The keyword `void` explicitly indicates that the function takes no arguments. If you omit `void` and leave the
parentheses empty, C++ interprets this as an implicit declaration that there are no arguments.

```cpp
myGuess = rand();   // function call with no arguments
```

There are some functions that have no return value. You indicate this in the prototype by using the keyword
`void` for a return type.

```cpp
void bucks(double);  // prototype for function with no return value
```

Because `bucks` doesn't return a value, you can't use this function as part of an assignment statement or of
some other expression. Instead, you have a pure function call statement:

```cpp
bucks(1234.56);         // function call, no return value
```
